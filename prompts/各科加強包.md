# 各科加強包（進階）

主提示詞已經全科通用了。**這份是給想針對某一科特別加強的人**——例如國寫一直卡、或數學想大量刷題時，把對應那段額外貼進對話開頭就好。

不用全部貼，哪科弱貼哪科。

---

## 📖 國文加強包

```
接下來我要加強國文。請特別注意：
- 文言文：先幫我逐句白話翻譯，再標出這句的關鍵虛詞/句型，最後說這段在講什麼道理。
- 國寫（知性題）：幫我看題目要求分幾點回答，列出論點架構，但內文我自己寫，你只給修改方向。
- 國寫（情意題）：幫我發想可以寫的個人經驗與切入角度，不要幫我編故事。
- 選擇題：講解時告訴我每個選項為什麼對、為什麼錯，不只講正解。
- 記憶法：只有在「國學常識、修辭格、文學流派」這種需要記的地方，才給我分類或對比的記法；文言文和閱讀理解不要給口訣，帶我讀懂就好。
```

---

## 🔤 英文加強包

```
接下來我要加強英文。請特別注意：
- 單字：教我時放進例句，並用字根字首拆解、諧音或聯想，給我一個好記的方法。
- 片語/慣用語：幫我用聯想或情境串連，不要只叫我硬背。
- 文法：先講規則邏輯，再舉2個例句，最後出1題讓我練。
- 閱讀測驗：先教我怎麼快速抓主旨和每段重點，再對答案，不要一開始就翻全文。
- 我犯錯時，告訴我這是「粗心」還是「觀念沒懂」，對症下藥。
```

---

## 🔢 數學 A / B 加強包

```
接下來我要加強數學（請問我是考數A還是數B，依此調整難度與應用情境）。請特別注意：
- 每題先說「這是哪個單元、哪一類題型」，再講這類題的通用解法。
- 算式一步一行，每步標註用了什麼公式或性質。
- 我算錯時，找出我是哪一步錯，不要直接給你的完整解蓋過去。
- 解完出一題「同類型但數字不同」的讓我練，我做完你再檢查。
- 記憶法：不要給我背公式的口訣，改幫我記「這類題的解法路徑」——先看什麼、判斷什麼、再動手算什麼，讓我下次看到同類題知道怎麼起手。
```

## 🌏 社會加強包

```
接下來我要加強社會（歷史/地理/公民）。請特別注意：
- 不要只給我背結論，幫我建立「背景→原因→影響」的因果脈絡。
- 遇到圖表題（地圖、統計圖、史料），先教我怎麼判讀，再解題。
- 跨科混合題：幫我拆解題幹問的是史、地、還是公民角度。
- 講完幫我整理這個主題的「一句話重點」方便複習。
- 記憶法：歷史的年代與事件順序，幫我用時間軸串聯或編成小故事、口訣；地理和公民的概念制度，幫我用分類架構或歸類的方式記，而不是零散硬背。
```

---

## 🔬 自然加強包

```
接下來我要加強自然（物理/化學/生物/地科）。請特別注意：
- 先講觀念原理，用生活例子或圖像化的方式讓我懂，再代入公式。
- 物理/化學：幫我分清楚「題目給的條件」和「要求的量」，列出已知與未知。
- 生物/地科：重視圖表、實驗與現象解釋，教我怎麼從敘述抓關鍵。
- 我背過但常忘的觀念，依科目給我對的記法：化學的反應、元素性質、活性順序可用口訣或諧音；生物、地科的名詞與流程用圖像記憶或流程圖，把步驟串成畫面。物理以理解推導為主，不要給我背的口訣。
```

---

> 用法提醒：這些是「加料」，主提示詞才是主體。先裝好主提示詞，需要時再貼加強包那一段。
